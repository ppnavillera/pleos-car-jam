# 사운드팩 라이선스

## basic 팩

basic 팩의 모든 샘플은 `tools/soundgen/generate.py`로 직접 합성했고 외부 샘플을 쓰지 않았다.
별도 라이선스 제약 없음(프로젝트 라이선스를 따른다).

형식: 48000Hz / 16bit / mono PCM WAV. 파일명(확장자 제외)이 sampleId다.

| sampleId | 용도 | 비고 |
|---|---|---|
| drum_kick | 드럼 킥 | 피치 스윕 사인 + 클릭 |
| drum_snare | 드럼 스네어 | 하이패스 노이즈 + 사인 |
| drum_hihat | 드럼 하이햇 | 하이패스 노이즈, 짧은 감쇠 |
| drum_clap | 드럼 클랩 | 밴드패스 노이즈 3연타 + 꼬리 |
| bass_1_o1 | 베이스 1도(C2, 65.41Hz) | 사인 + 약한 배음 |
| bass_1_o2 | 베이스 1도(C3, 130.81Hz) | 사인 + 약한 배음 |
| bass_1_o3 | 베이스 1도(C4, 261.63Hz) | 사인 + 약한 배음 |
| bass_4_o1 | 베이스 4도(F2, 87.31Hz) | 사인 + 약한 배음 |
| bass_4_o2 | 베이스 4도(F3, 174.61Hz) | 사인 + 약한 배음 |
| bass_4_o3 | 베이스 4도(F4, 349.23Hz) | 사인 + 약한 배음 |
| bass_5_o1 | 베이스 5도(G2, 98.00Hz) | 사인 + 약한 배음 |
| bass_5_o2 | 베이스 5도(G3, 196.00Hz) | 사인 + 약한 배음 |
| bass_5_o3 | 베이스 5도(G4, 392.00Hz) | 사인 + 약한 배음 |
| mel_0 | 멜로디 C4 (261.63Hz) | 사인 + 비조화 배음 |
| mel_1 | 멜로디 D4 (293.66Hz) | 사인 + 비조화 배음 |
| mel_2 | 멜로디 E4 (329.63Hz) | 사인 + 비조화 배음 |
| mel_3 | 멜로디 G4 (392.00Hz) | 사인 + 비조화 배음 |
| mel_4 | 멜로디 A4 (440.00Hz) | 사인 + 비조화 배음 |
| mel_5 | 멜로디 C5 (523.25Hz) | 사인 + 비조화 배음 |
| mel_6 | 멜로디 D5 (587.33Hz) | 사인 + 비조화 배음 |
| mel_7 | 멜로디 E5 (659.25Hz) | 사인 + 비조화 배음 |
| fx_impact | FX 임팩트 | 저음 쿵 + 노이즈 버스트 |
| fx_riser | FX 라이저 | 1초 이내 상승 노이즈 + 사인 |
| fx_sweep | FX 스윕 | 필터 스윕 노이즈 |
| fx_zap | FX 레이저 | 하강 피치 사인 + 배음 |
| metro_hi | 메트로놈 강박 | 약 1500Hz 클릭 |
| metro_lo | 메트로놈 약박 | 약 1000Hz 클릭 |

## car 팩 (차량 사운드팩)

car 팩의 모든 샘플도 `tools/soundgen/generate_car.py`로 직접 합성했다(수식, 고정 난수 시드). 외부 샘플도, 실제 차량 녹음도 쓰지 않았다. 실제 경적을 울리거나 차량을 제어하지 않는다. 별도 라이선스 제약 없음(프로젝트 라이선스를 따른다).
형식과 sampleId는 basic 팩과 같다(48000Hz / 16bit / mono PCM WAV, 27개). 같은 이름이 팩마다 다른 악기다.

| sampleId | 차량 팩에서의 소리 | 합성 방법 |
|---|---|---|
| drum_kick | 도어 닫힘 "쿵+탁" | 피치 스윕 사인(130→58Hz) + 저역 노이즈 + 늦게 오는 래치 클릭 |
| drum_snare | 트렁크 닫힘 "쾅" | 사인 스윕(220→110Hz) + 대역 노이즈 꼬리 |
| drum_hihat | 방향지시등 릴레이 "똑" | 짧은 밴드패스 클릭 + 3.1kHz 링 |
| drum_clap | 안전벨트 버클 "찰칵" | 금속 클릭 두 번 |
| bass_{1,4,5}_o{1,2,3} | 경적 음색, 음높이만 바꿈 (짧고 부드럽게) | 공명 대역(720Hz) 근처가 강한 가산 합성, ±0.6% 어긋난 두 소리, 부드러운 어택, 2단 로우패스, 0.5초, 피크 0.62 |
| mel_0..7 | 같은 경적 음색, 높은 음역 | 위와 같고 0.42초 |
| fx_impact | 경적 한 번 | 392Hz+494Hz 두 음을 짧게 다듬음 |
| fx_riser | 시동음 | 점점 빨라지는 크랭킹 펄스 → 낮은 공회전 럼블 |
| fx_sweep | 경고 차임 "딩-동" | 1175Hz → 880Hz 두 음 |
| fx_zap | 후방 감지 경고 "삑삑" | 1050Hz 짧은 비프 두 번 |
| metro_hi / metro_lo | 방향지시등 릴레이 "딱" / "똑" | 2.6kHz / 1.7kHz 링 클릭 |

소리가 듣기에 어떤지는 합성 수식으로 알 수 없어 사람이 귀로 확인해야 한다(`docs/PROGRESS.md`).
