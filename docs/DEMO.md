# 시연 스크립트 (초안, T2-10)

Virtual Console 조작 순서와 기대 결과. 3분 안에 끝나게 짰다. `[확인됨]`은 `scripts/check.sh`나 에이전트의 에뮬레이터 실측으로 확인한 것이고, `[귀·눈]`은 사람이 직접 보고 들어야 하는 것이다(아직 사람 확인 전).

## 준비 (시연 전)

0. **시연은 전체 화면(에뮬레이터 창 전체)으로 한다.** 좁은 창에서는 방향지시등 카메라 창을 피하지 못한다(알려진 제약).

1. 에뮬레이터 `Pleos_Connect_v2.1.0` 부팅. 앱 설치: `adb install -r app/build/outputs/apk/release/app-release.apk` (debug와 서명이 달라 `adb uninstall app.pjam.studio`를 먼저 해야 할 수 있다).
2. `adb forward tcp:8088 tcp:8088` 뒤 브라우저로 `http://127.0.0.1:8088/` (Virtual Console).
3. Virtual Console에서 **Motion → Gear Selection = P**, **Climate → HVAC Power = On**, **HVAC Dual = Off**. (Power가 꺼져 있으면 공조 신호가 안 올 수 있다. 앱의 "내 차 장비"가 이 사유를 보여 준다.)
4. 방향지시등·브레이크는 **Off / 0%** 로 둔다. 방향지시등은 꺼진 상태에서 켜지는 순간만 입력이다.
5. 앱을 열어 둔다. 오른쪽 위 "내 차 장비"에서 줄이 `연결됨`인지 한 번 본다.

## 막혔을 때

- **차량 입력이 하나도 안 올 때**: 화면 패드와 핸들 대체 3버튼으로 같은 연주를 한다(내 차 장비에 "차량 신호 없음 · 화면 조작으로 대체"). 시연은 계속된다.
- **공조를 바꿨는데 트랙이 안 바뀔 때**: "내 차 장비"에 "공조 전원이 꺼져 있어요"가 보이면 Virtual Console의 HVAC Power를 켠다.
- **앱이 가려져 있을 때**: 기어가 P가 아니다. `scripts/vc.sh gear P`.
- **소리가 안 날 때**: 에뮬레이터 볼륨, 다른 앱의 오디오 포커스. 앱을 다시 열어 ▶를 누른다.
- **Virtual Console이 안 열릴 때**: `adb forward tcp:8088 tcp:8088`을 다시 하고 에뮬레이터가 v2.1.0 이상인지 본다.

## 알려진 제약 (시연 중 설명할 수 있게)

- 방향지시등을 켜면 플랫폼의 사각지대 카메라 창이 앱 위 왼쪽에 뜬다. 켜 둔 동안 계속 떠 있다(Off로 끄면 사라진다). 앱은 그 자리에 필수 조작을 두지 않는다. 좁은 창(멀티 윈도우)에서는 이 창을 피하지 못한다. 그래서 **시연은 전체 화면으로 한다.**
- 에뮬레이터의 브레이크 카드는 0~100%지만 SDK는 눌림/뗌(Boolean)만 준다. 방향지시등은 좌/우 깜빡임·점멸을 구분하지 않고 `LEFT`/`RIGHT`로 온다.
- 와이퍼·창문·풍량·온도·드라이브 모드는 이번 버전에서 쓰지 않는다(드라이브 모드는 에뮬레이터 미지원).
