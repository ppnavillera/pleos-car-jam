## 2026-11-15 (1) 녹음 방식 변경 (계획서 3.3, T3-9)

써 보니 "2마디 뒤 자동 종료"가 불편했다. 3.3의 녹음 흐름을 아래로 바꾼다. 사용자 결정.

| 항목 | 계획서 3.3 | 변경 |
|---|---|---|
| 루프 길이 | 2마디(32스텝) | 같다 |
| 녹음 종료 | 2마디가 끝나면 자동 종료, 녹음 버튼을 누르면 그때까지 내용으로 확정 | **녹음 버튼을 다시 누를 때까지 계속된다.** 루프가 돌 때마다 앞 바퀴에 친 노트가 재생되고 새 입력이 그 위에 쌓인다 |
| 덮어쓰기 | 녹음이 시작되는 순간 그 트랙의 기존 노트를 지운다 | **같다. 단 한 번만.** 시작 순간 지운 뒤로는 바퀴가 돌아도 지우지 않고 쌓기만 한다 |
| 메트로놈 | 카운트인(1마디)과 루프 중 녹음 직전 1마디 | 카운트인과 **녹음 중 내내 매 박** 울린다. 마디 첫 박은 강세(`metro_hi`). 녹음이 끝나면 꺼진다. 트랙에는 기록하지 않는다 |
| 녹음 중 다른 트랙 선택 | (정의 없음) | **현재 녹음을 끝내고(내용 유지) 선택만 바꾼다.** 카운트인 대기 중이었다면 취소한다. 재생은 계속된다 |
| 녹음 중 기어 이탈 | 녹음 취소, 그때까지 찍힌 내용 유지, 재생 정지 | 녹음을 끝내고 내용을 유지한다. 재생도 정지한다. 백그라운드 진입도 같다 |
| T3-9 "겹쳐 넣기" 옵션 | 옵션으로 제공 | **없앤다.** 쌓기가 기본 동작이라 옵션이 필요 없다. T3-9는 "AUTO 연동 무시 옵션"만 남는다 |

구현 메모 (엔진 `LoopEngine`)
- 녹음 중 입력은 루프 시작 시각이 아니라 **아직 안 울린 다음 스텝**을 기준으로 절대 스텝을 구한 뒤 `floorMod(abs − origin, 32)`로 루프 위치에 감는다(`Quantizer.roundedSteps`). 여러 바퀴가 이어져도, 템포가 중간에 바뀌어도 맞는다.
- 녹음 중인 트랙도 재생한다. 이중 발음은 "방금 친 입력이 아직 안 온 스텝으로 반올림된 경우"에만 생기므로, 그 스텝에서 같은 노트를 한 번 건너뛴다(`skipOnce`).
- 새 명령 `FinishRecord`: 녹음 중이면 끝내고, 대기 중이면 취소한다. 트랙 선택 변경과 기어 이탈이 이것을 보낸다. 엔진 상태는 엔진 스레드만 바꾼다는 원칙을 지키기 위해 명령으로 보낸다.
- 녹음이 끝나면 로그에 `REC end <트랙> notes=N (사유)`가 남는다. `scripts/e2e_record_loop.sh`가 이 문자열을 읽는다.
- 단위 테스트: 2마디 뒤에도 녹음 유지, 앞 바퀴 노트 재생과 쌓기, 시작 순간 한 번만 지우기, 녹음 중 매 박 메트로놈과 종료 후 소등, 이중 발음 방지, 템포 변경 중 퀀타이즈, `FinishRecord`, 정지 시 녹음 종료.
